# Mesa Virtual

Apresentador cinematográfico para mestres de RPG: tela da TV separada das anotações do mestre, transições, efeitos de ambiente, trilhas com crossfade, botões de som, retratos dos jogadores por cima do cenário, caminhos alternativos e sessões salvas.

Tudo roda no navegador. Imagens, sons e sessões ficam guardados no próprio navegador de quem usa (e, se quiser, numa pasta do Google Drive para computador). Nada é enviado para servidor.

Funciona melhor no Chrome ou no Edge. No celular, use "Adicionar à tela inicial" para instalar como app.
